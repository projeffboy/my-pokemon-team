# UI Tests for Main Section

- This test md file outlines the UI tests for the main section of the website.
- Test scenarios that are implicitly covered by E2E testing should not be covered here
- Unit tests that only interact with snackbars, which is technically an external UI element outside of the unit, are still considered unit tests by this project's definition.
- Each section below has its own folder with two possible test files: `<section>/(unit|integration)-tests.spec.ts`
