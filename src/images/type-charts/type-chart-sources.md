# Type chart image sources

These images are bundled with the app so the type chart dialog does not depend on external image hosts.

- `type-chart-list.webp`: [original PNG](https://i.pinimg.com/originals/7b/c6/58/7bc65872baa79ac690e9e4ae1aa8cb64.png), 820 × 544. A larger JPEG copy was checked but had visibly softer text, so the original PNG was kept as the source.
- `type-chart-infographic.webp`: [author's corrected PNG](https://i.imgur.com/fylyCdC.png), 1322 × 860. The [original post](https://www.reddit.com/r/pokemon/comments/1oq3rg/was_getting_frustrated_finding_an_easytoread_type/) links to this version and permits saving and reposting it.

Downloaded on September 8, 2026, and converted from the PNGs to lossless WebP with `cwebp -lossless -z 9` on September 21, 2026, which keeps every pixel at roughly a quarter of the size. Neither image was resized. `type-chart.webp` was converted from the PNG already in the repository.
