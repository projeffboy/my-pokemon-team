# Header face sources

Downloaded on October 9, 2026. Both images retain their original PNG artwork, dimensions, and transparency without cropping or resizing.

- `garchomp-shuffle-face.png`: Garchomp's icon from Pokémon Shuffle, downloaded from [Bulbagarden Archives: Shuffle445.png](https://archives.bulbagarden.net/wiki/File:Shuffle445.png) ([original PNG](https://archives.bulbagarden.net/media/upload/5/54/Shuffle445.png)). The canvas is 256 × 256 pixels; nontransparent artwork occupies 198 × 190 pixels, starting at (26, 28). `public/favicon-garchomp-2026.png` is an identical copy, given a fresh filename because public images are cached as immutable.
- `indeedee-masters-face.png`: male Indeedee's icon from Pokémon Masters EX, downloaded from [Bulbagarden Archives: MastersIcon0876.png](https://archives.bulbagarden.net/wiki/File:MastersIcon0876.png) ([original PNG](https://archives.bulbagarden.net/media/upload/9/94/MastersIcon0876.png)). The canvas is 128 × 128 pixels; the nontransparent artwork spans its full bounds. Indeedee does not have a Pokémon Shuffle icon, so this official head icon is used instead.

These are official Pokémon game images. The source pages identify them as copyrighted game imagery and label their use as fair use; they are not freely licensed artwork. Pokémon © Nintendo, Creatures Inc., and GAME FREAK inc.

The download sources for the older Venusaur and Charizard face images in this directory were not recorded.
