# Header image sources

The old website restores these original files byte for byte from
[commit 2d2bff3](https://github.com/projeffboy/my-pokemon-team/commit/2d2bff34afc852e7413c979ed4d10ee1f2af7f03):

- `landorus-face.png`: the original `src/landorus-face.png`, Pokemon Shuffle artwork.
- `ogerpon-teal-mask-by-jormxdos.png`: the original `src/ogerpon-teal-mask-by-jormxdos.png`, Shuffle-style fan art by JormXDOS.
- `public/favicon-landorus.png`: the original `public/favicon.ico`, the Landorus favicon (PNG bytes despite its original `.ico` extension). The new filename avoids the immutable cache on the previously deployed favicon.

Landorus is on the left of the title and Teal Mask Ogerpon is on the right, matching the original header.

The New website button uses `garchomp-shuffle-face-cropped.svg`, copied unchanged from the main website. Its SVG wrapper embeds the original Pokemon Shuffle PNG from [Bulbagarden Archives: Shuffle445.png](https://archives.bulbagarden.net/wiki/File:Shuffle445.png), with transparent margins trimmed by its view box.
