# Type icon sources

The 18 type icons shown before a move's name, bundled so they load with the app.

Downloaded on October 2, 2026, from the `icons/` folder of [partywhale/pokemon-type-icons](https://github.com/partywhale/pokemon-type-icons) at commit `fcbe697`, unchanged. They are James Watkins's vector recreations of the type icons in Brilliant Diamond, Shining Pearl, Legends: Arceus, Scarlet, and Violet, released under the MIT license. Each is a 256 × 256 SVG with the type's colour in a circle and the symbol in white.
